افتح موجّه الأوامر داخل هذا المجلد ونفّذ بالترتيب:


الخطوة 1 — تثبيت الحزم (يستغرق 1-3 دقائق)
────────────────────────────────────────
    npm install


الخطوة 2 — ضع رابط قاعدة البيانات
────────────────────────────────────────
افتح الملف  .env.local  بأي محرر نصوص
واستبدل السطر الأخير برابط Neon الخاص بك.

من أين تحصل عليه:
    console.neon.tech  ←  مشروعك  ←  Connect  ←  Connection string

تنبيه: سطر واحد فقط، بين علامتَي تنصيص، بلا فواصل أسطر.


الخطوة 3 — جهّز قاعدة البيانات (مرة واحدة فقط)
────────────────────────────────────────
في Neon، من SQL Editor، نفّذ بالترتيب:

    db/schema.sql     ثم     db/seed.sql

إن كنت قد نفّذتهما سابقاً على نفس القاعدة، تخطَّ هذه الخطوة.


الخطوة 4 — شغّل
────────────────────────────────────────
    npm run dev

ثم افتح المتصفح على:   http://localhost:3000


═══════════════════════════════════════════════════════
  التحقق السريع
═══════════════════════════════════════════════════════

    npm test          →  المتوقع:  # pass 10
    npm run typecheck →  المتوقع:  لا مخرجات (صفر أخطاء)

    localhost:3000/api/health  →  "ok":true  و  35 منشأة


═══════════════════════════════════════════════════════
  إن ظهر خطأ
═══════════════════════════════════════════════════════

الصفحة تعطي 500
    السبب الحقيقي مطبوع في نافذة npm run dev — اقرأها.

DATABASE_URL غير معرّف
    الملف .env.local مفقود، أو حُفظ باسم .env.local.txt
    تحقّق:   dir .env*

password authentication failed
    الرابط ناقص أو مكسور على سطرين — انسخه من جديد من Neon.

الخريطة رمادية فارغة
    تعذّر الوصول لخوادم الخرائط — جرّب شبكة أخرى.
    النقاط والبيانات تعمل بغض النظر عن الخلفية.

بعد أي تعديل على .env.local
    أوقف الخادم بـ Ctrl+C ثم شغّله من جديد — تُقرأ عند الإقلاع فقط.
